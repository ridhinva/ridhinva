About Me

Background and what I do.

I'm a bug bounty hunter and security researcher specializing in web application security, API testing, and exploit development.

I find vulnerabilities in real-world applications, build open-source exploit tools, and contribute to the security community. My work spans the full spectrum — from SQL injection and cross-site scripting to binary exploitation and cryptographic attacks.

Active on HackerOne, Hack The Box, and multiple bug bounty programs. Every tool I build is released publicly on GitHub with full documentation.

Core Focus Areas:

  • Web application penetration testing
  • API & GraphQL security assessments
  • Exploit development & reverse engineering
  • Cloud infrastructure security (AWS, Azure, GCP)
  • Cryptographic attack analysis
  • Open-source security tooling
